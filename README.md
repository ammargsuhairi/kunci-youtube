# Kunci YouTube

Mengunci layar sentuh hanya saat YouTube terbuka, supaya anak kecil tidak kepencet ke mana-mana.

## Build lewat GitHub
1. Push semua file ini ke repo GitHub (branch main).
2. Buka tab Actions, tunggu workflow "Build APK" selesai.
3. Unduh artifact KunciYouTube-debug-apk, ekstrak, lalu pasang app-debug.apk di HP.

## Pakai
Aktifkan "Kunci YouTube" di Pengaturan > Aksesibilitas.
Buka kunci: tahan area kiri atas dan kanan bawah bersamaan 2,5 detik (agak ke dalam dari tepi layar).
